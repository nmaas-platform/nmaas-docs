# Discontinuing Moodle and Jenkins Support in nmaas

Support for Moodle and Jenkins has been discontinued in nmaas. Both applications have been removed from the application catalogues and can no longer be deployed by nmaas users.

Jenkins has been removed from both the nmaas Virtual NOC (vNOC) and nmaas Virtual Lab (vLAB) catalogues. Moodle was only ever offered in the vLAB catalogue, so it has been removed from vLAB alone. The vNOC catalogue never included Moodle and is otherwise unaffected.

Existing Moodle and Jenkins deployments will keep running for now. However, the nmaas team will no longer provide updates for either application, so existing instances will not receive new versions or security fixes.

If you have any questions about this change, please get in touch with the nmaas team using the [contact form](https://vnoc.nmaas.eu/about).
